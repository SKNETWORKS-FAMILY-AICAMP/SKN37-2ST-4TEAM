# 화면을 수정하는 팀원을 위한 인수인계

## 먼저 알아둘 점

화면 수정과 모델 교체는 별개입니다. 디자인·메뉴·문구만 바꿀 때는 `service/app.py`와 `service/ui.py`를 중심으로 수정하세요.
`run.py`가 실행 진입점이며, 하나의 실행 버튼으로 앱을 시작하기 위해 화면·모델·저장 코드를 한 파일에 합칠 필요는 없습니다.

## 어떤 파일을 고치나요?

| 파일 | 역할 | 수정하는 경우 |
|---|---|---|
| `run.py` | 실행 환경 점검과 앱 시작 | 실행 방식·접속 번호 |
| `service/app.py` | 메뉴와 화면 배치, 입력·버튼 연결 | 화면 이동·문구·운영 흐름 |
| `service/ui.py` | 팀원 원본 디자인, 색상·카드·하단 막대 | 디자인 변경 |
| `service/operating_views.py` | 홈의 대응 결과 입력·조회 | 캠페인 결과 화면 |
| `service/operations.py` | 대응 결과 계산·저장, 보고서 생성, 설정 설명 | 대응 지표·보고서 |
| `service/core.py` | 모델 로딩, 최적 조합 계산, 정형 입력과 추천 대응 | 모델 추론·비중·판정 기준 |
| `service/sequence_runtime.py` | 시퀀스 연결·검사·추론·등록 | 신경망 입력·고객 연결 |
| `models.py` | 팀원이 만든 신경망 구조 | 구조 자체가 바뀐 모델 교체 |
| `service/validation.py` | 정형 자료 검사 | 입력 항목·검사 기준 |
| `service/storage.py` | 기준일별 고객표와 수정 이력 | 저장 방식 |

## 이전에 연결을 보류했던 이유와 이번 변경

이전 자료에는 가중치는 있었지만 행동 사전·시퀀스 생성 코드·고객 번호 연결 규칙이 없었습니다.
기존 전체 배열의 정답도 고객표와 맞지 않아, 이름만 보고 고객에게 붙이거나 임시 입력을 넣지 않았습니다.

수정본에는 학습·검증·최종 평가별 배열과 대응하는 고객표가 추가됐습니다.
수정된 학습 코드가 각 배열의 같은 행을 해당 고객표의 같은 행으로 사용하며,
그 방식으로 재현한 신경망·정형 모델·최적 결합 예측이 저장된 예측과 일치하는 것을 확인했습니다.
따라서 **제공된 기준일의 고객은 준비된 입력을 사용해서 연결**했습니다.

다만 **원시 행동 로그에서 같은 번호의 배열을 새로 만드는 코드는 여전히 없습니다.**
모델을 실행할 수 있게 된 것과 신규 로그 자동 변환이 완성된 것은 다릅니다.
기존 원시 시퀀스와 제공 배열의 관찰 기간·행동 의미가 정확히 일치하는지는 생성 코드로 추가 확인해야 합니다.

## 현재 확정 조합과 점수

`model/best_hybrid_config.json`에 저장된 다음 설정을 사용합니다.

```
에이다부스트 출력 × 0.60 + 장단기 기억 신경망 출력 × 0.40
판정 기준 = 0.39822677201244505
```

`Service.scores`는 최적 조합 모드에서 모델 출력에 100을 곱한 점수를 반환합니다.
`Service.threshold`는 저장된 판정 기준에도 100을 곱하므로 약 39.822677점을 사용합니다.
**확률 단위의 판정 기준 0.398227과 점수 단위 39.822677을 섞지 마세요.**
상세 옵션의 단독·수동 결합 모드는 기존 백분위 점수를 사용합니다. 두 눈금은 서로 바꿔 쓸 수 없습니다.
확정 조합은 앱에서 다시 탐색하거나 검증 자료로 다시 튜닝하지 않습니다.

## 시퀀스가 고객에게 연결되는 방식

`SequenceBank`는 다음 두 파일의 같은 행을 고객 번호로 묶습니다.

```
data/processed/train.npy + train_20181101_v1.csv
data/processed/valid.npy + valid_20181101_v1.csv
data/processed/test.npy  + test_20181101_v1.csv
```

제공 자료의 기준일은 2018-11-01입니다. 각 입력은 정수 행동 번호 50개입니다.
고객표와 배열을 따로 정렬하면 연결이 깨집니다. 정렬이 필요하면 동일한 고객 번호 순서로 함께 정렬하세요.
원래 고객의 정형 집계가 달라졌거나 기준일이 바뀌면 기존 시퀀스를 자동으로 재사용하지 않습니다.

## 신규·갱신 고객 등록

고객 자료 화면에서 먼저 같은 기준일의 신경망 입력을 등록하고, 이어서 정형 고객표를 추가·교체합니다.
신경망 입력은 객체 저장을 사용하지 않는 압축 배열 파일이며 두 항목이 필요합니다.

| 항목 | 조건 |
|---|---|
| `user_id` | 중복 없는 고객 번호 문자열 목록 |
| `tokens` | 행 수가 고객 수와 같은 정수 배열, 고객당 길이 50, 번호는 0 이상 50 미만 |

다음 코드는 **이미 학습 기준으로 만들어진 입력과 확인된 고객 번호를 묶는 포장 예시**입니다.
행동 이름을 숫자로 바꾸는 코드가 아니며 정형 피처 14개로 신경망 입력을 만들 수는 없습니다.

```python
import numpy as np

# 반드시 배열의 행과 연결이 확인된 고객 번호를 사용하세요.
고객번호 = np.asarray(확인한_고객번호_목록, dtype=str)
시퀀스 = np.asarray(학습_기준으로_변환한_행동_배열, dtype=np.int64)
np.savez_compressed("고객별_신경망입력.npz", user_id=고객번호, tokens=시퀀스)
```

화면에서 기준일을 선택하고 같은 행동 번호·길이·관찰 기간임을 확인한 뒤 등록합니다.
등록 자료는 `service_data/sequence_inputs`에 보관하며, 같은 기준일·고객 번호의 최신 등록을 사용합니다.
이 폴더는 운영 자료이므로 깃허브 배포본에 넣지 않습니다.

## 새 행동 변환 코드를 받으면

1. 학습 당시 행동 사전, 모르는 행동 처리, 빈 입력 처리, 앞·뒤 자르기와 채우기 규칙을 확인합니다.
2. 기준일 이전 28일만 사용하고, 이후의 해지 완료·해지 직전 행동이 섞이지 않는지 확인합니다.
3. 고객 번호를 보존한 변환 함수를 `service/sequence_runtime.py` 또는 별도 모듈에 추가합니다.
4. 변환한 고객 몇 명의 결과가 팀원이 만든 정답 입력과 완전히 같은지 검사합니다.
5. 검사가 끝나면 고객 자료 업로드 흐름에 연결하고 수동 입력 등록을 보조 기능으로 남깁니다.

행동 번호를 알파벳순이나 발견 순서로 임의 생성하면 안 됩니다. 번호 범위가 같아도 학습 때 의미가 다르면 다른 예측이 됩니다.
자료가 없다고 0 배열을 대신 넣거나, 고객 순서를 추측하거나, 기존 시퀀스를 다른 날짜에 재사용하지 마세요.

## 모델 파일을 교체하면

- 정형 모델은 피처 이름과 순서·요금제 인코딩이 같은지 확인합니다.
- 신경망 구조가 같으면 가중치와 대응 입력을 함께 교체하고 저장 예측을 재현해 비교합니다.
- 구조나 시퀀스 규칙이 달라지면 `models.py`와 `SequenceAdapter`도 함께 수정합니다.
- 최적 신경망 종류를 장단기 기억 모델에서 다른 구조로 바꾸면 설정 파일만 바꿔서는 연결되지 않습니다. 현재 지원하지 않는 종류는 오류로 안내합니다.
- `best_hybrid_config.json`의 모델 이름·비중·판정 기준과 실제 연결이 맞는지 확인합니다.
- 교체 후 앱을 완전히 재시작하고 검사를 실행합니다. 변경 감지는 편의 기능이며 호환성 검사를 대신하지 않습니다.

`service_signature`는 모델, 정의 파일, 설정, 분할 입력과 등록 입력의 변경을 감지해 기존 예측 임시 저장을 갱신합니다.

## 화면 설명에서 주의할 점

고객별 행동 영향은 **시퀀스를 고정하고 정형 입력만 바꾼 비교**입니다.
신경망이 어떤 행동을 중요하게 봤는지 분석한 값이나 실제 캠페인의 효과가 아닙니다.
모델 지표 설명은 보고서에 두고 운영 화면은 고객 대응에 집중하도록 유지했습니다.

최적 탐색이 최종 평가 자료에서 조합·비중·판정 기준을 골랐으므로 저장된 수치를 독립적인 최종 성능으로 표현하지 마세요.
이번 연결 확인도 재학습·재탐색이나 새로운 최종 성능 평가가 아닙니다.

## 수정 후 확인

```powershell

python -m unittest discover -s service -p "test_*.py" -v
```

홈·고객 상세·캠페인·고객 자료·설정 화면을 확인합니다.
특히 신규 고객·다른 기준일·변경된 정형 집계가 올바른 시퀀스 없이 통과하지 않는지 확인하세요.
