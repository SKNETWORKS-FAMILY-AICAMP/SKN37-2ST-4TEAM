# 음악 고객 이탈 대응 앱

운영자가 이탈 위험 고객을 확인하고 맞춤 대응을 제공한 뒤, 실제 14일 이탈 결과를 기록하는 앱입니다.
팀원이 만든 디자인을 유지하며 관리 목록을 홈으로 사용합니다.

## 다른 노트북에서 실행

윈도 환경과 파이썬 3.12에서 확인했습니다. 압축 파일은 모두 풀어 주세요.

1. 파이썬 3.12가 설치되어 있는지 확인합니다.
2. 처음 한 번 `처음설치.bat`을 더블클릭합니다. 필요한 프로그램을 받으므로 인터넷 연결이 필요합니다.
3. 설치가 끝나면 `앱실행.bat`을 더블클릭합니다. 다음부터는 이 파일만 실행하면 됩니다.
4. 실행 창을 열어 둔 상태에서 브라우저의 앱을 사용합니다. 창을 닫으면 앱도 종료됩니다.

앱 실행에 필요한 모델과 시연 자료는 배포 폴더에 포함되어 있습니다. 운영 중 저장한 고객·대응 기록은 포함하지 않았습니다.

## 편집기에서 실행 버튼 사용

`run.py`를 열고 설치된 실행 환경을 선택한 뒤 파이썬 실행 버튼을 누르세요.
`service/app.py`를 일반 파이썬으로 직접 실행하는 대신 `run.py`를 사용합니다.

명령어를 쓰는 경우:

```powershell
.\.venv\Scripts\python.exe run.py
```

기존 학습 환경이 준비되어 있다면 그 환경에서 `python run.py`를 실행할 수도 있습니다.
접속 번호가 이미 사용 중일 때는 `python run.py --port 8502`처럼 바꿉니다.

설치·필수 파일만 확인하려면:

```powershell
python run.py --check
```

## 현재 적용한 모델

- 에이다부스트 60% + 장단기 기억 신경망 40%의 모델 출력 결합
- 저장된 판정 기준: 0.39822677201244505
- 앱은 출력에 100을 곱해 표시하므로 기본 판정 기준은 약 39.822677점입니다.
- 모델 출력이 실제 해지율로 보정된 확률이라는 뜻은 아닙니다.
- 앱을 시작할 때 학습하거나 최적 조합을 다시 탐색하지 않습니다.

제공된 분할 시퀀스로 재현한 신경망·에이다부스트·조합 예측이 팀원이 저장한 예측과 일치하는 것을 확인했습니다.
원시 행동 로그에서 신경망 입력을 만드는 코드는 포함되어 있지 않습니다.
제공된 고객 이외의 신규·갱신 고객은 **같은 기준일의 정형 자료와 신경망 입력을 함께 등록**해야 합니다.
자료가 없으면 오래된 시퀀스를 재사용하지 않고 등록 안내를 표시합니다.

## 화면

| 메뉴 | 운영자가 하는 일 |
|---|---|
| 홈 | 대응 대상 선정, 추천 대응 확인, 목록 내려받기, 실제 대응 결과 기록·조회 |
| 고객 상세 | 고객별 위험 신호와 대응 제안 확인 |
| 캠페인 | 인원·비용·성공률을 가정한 계획 비교 |
| 고객 자료 | 정형 자료와 준비된 신경망 입력 등록, 기준일별 보관·복원 |
| 설정 | 확정 조합 확인, 상세 모델 선택, 보고서 자료 내려받기 |

## 개발·인수인계

[화면 수정과 모델 교체 안내](docs/화면수정_모델연결_인수인계.md)에 파일별 역할과 신경망 입력 조건을 정리했습니다.
화면만 바꿀 때는 모델과 시퀀스 코드를 수정할 필요가 없습니다.

```powershell
python -m unittest discover -s service -p "test_*.py" -v
```

모델 평가 설명은 `reports/모델평가_보고서자료.md`에 있습니다.
팀원 탐색은 최종 평가 자료로 조합·비중·판정 기준을 선택했으므로 기록된 성능을 독립적인 최종 평가 성능으로 발표하면 안 됩니다.
화면의 추천 대응과 점수 변화도 실제 대응 효과를 뜻하지 않습니다. 실제 대응 결과는 별도로 기록합니다.

## 깃허브에 올리기

배포용 압축을 풀고 그 안의 파일과 폴더를 저장소에 올리세요. 압축 파일 자체만 올리면 코드 화면에서 바로 살펴보기 어렵습니다.
기존 저장소에 합칠 때는 이 배포본의 폴더 구조를 유지합니다. 입력 자료 경로는 `data/processed`입니다.

`.gitignore`는 실행 환경, 운영 고객 자료, 대응 결과, 개인 설정과 대용량 원본을 제외합니다.
기존 저장소에서 이미 추적 중인 운영 자료는 제외 규칙만 추가해도 자동으로 제거되지는 않으므로 올릴 파일 목록을 확인하세요.
이 작업에서는 원격 저장소로 업로드하거나 변경 내용을 게시하지 않았습니다.
