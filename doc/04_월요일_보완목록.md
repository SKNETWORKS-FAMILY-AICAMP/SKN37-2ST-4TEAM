# 월요일 보완 목록

작성 기준은 2026년 10월 30일이며 보완일은 11월 2일 월요일입니다. 주말 작업을 전제로 하지 않습니다. 문서와 앱의 현재 상태를 보존하고 월요일에 근거가 확보된 부분만 수정합니다.

## 현재 확정한 범위

- 고객 단위 정형 자료 18,139명과 공통 분할, 이탈 정답 1,035명
- 전처리 검사 결과와 개인 기준 모델 세 가지의 저장 실험 결과
- 수정본의 에이다부스트 60%와 장단기 기억 신경망 40% 연결
- 제공 입력으로 재현한 예측과 저장 예측의 일치
- 앱 기능 검사 20개 통과와 현재 실행 환경에서의 간편 시작 확인
- 실제 캠페인 효과, 독립적인 최종 성능, 신규 원시 로그 자동 변환은 아직 확인하지 않음

## 월요일 권장 진행 순서

1. 오전 첫 확인에서 입력 생성 근거와 평가 절차를 팀 전체가 공유합니다.
2. 독립 평가를 새로 만들 수 있는지 결정합니다. 시간이 부족하거나 입력이 미확인이라면 탐색 결과와 한계를 정확히 발표하는 방향으로 확정합니다.
3. 화면 담당자가 수정한 버전으로 시연을 확인하고 발표 첫 화면의 이미지·문구를 갱신합니다.
4. 결과서와 발표 대본의 수치·자료 이름·판정 기준을 맞추고 한 차례 리허설합니다.
5. 발표 전 사용할 버전을 동결하고 실행 폴더와 문서를 함께 보관합니다.

오후 2시 발표 준비를 기준으로 점심 전에는 수치와 설명을 고정하고, 이후에는 오류 수정과 시연 확인에 집중하는 것을 권장합니다. 실제 수업 일정에 맞춰 조정하세요.
