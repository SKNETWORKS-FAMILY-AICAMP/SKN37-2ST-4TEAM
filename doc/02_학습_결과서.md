# 인공지능 학습 결과서

작성 기준은 2026년 10월 30일입니다. 개인 기준 모델 실험, 팀원의 확장 탐색, 현재 앱의 연결 점검을 구분해 기록합니다. 이 문서는 독립적인 최종 성능을 확정한 결과서가 아니라 월요일 보완을 위한 현재 상태의 결과서입니다.

## 1 목표와 학습 자료

최근 28일의 행동으로 향후 14일 해지를 예측하고 운영자가 관리할 고객의 우선순위를 제공합니다. 정형 자료는 18,139명과 입력 피처 14개이며, 고객 번호·이탈 정답·분할은 입력에서 제외합니다.

| 구분 | 고객 수 | 이탈 고객 수 | 이탈 비율 |
| --- | --- | --- | --- |
| 학습 | 12,697 | 724 | 5.70% |
| 검증 | 2,721 | 156 | 5.73% |
| 최종 평가용으로 분리한 자료 | 2,721 | 155 | 5.70% |

## 2 실험의 구분과 평가 원칙

| --- | --- | --- |

| 팀원 조합 탐색 | 최종 평가용 자료에서 조합·비중·재현율 중시 판정 기준을 선택 | 독립적인 최종 성능으로 주장할 수 없음 |
| 현재 앱 연결 점검 | 저장된 조합과 판정 기준을 그대로 적용 | 재학습·재탐색 없이 예측 재현과 운영 기능을 확인 |

평균정밀도는 이탈 고객을 상위에 배치하는 능력을 요약합니다. 수신자 곡선 면적은 두 클래스의 순위 구분을 봅니다. 정밀도는 선정 고객 중 실제 이탈 비율, 재현율은 실제 이탈 중 찾아낸 비율입니다. 판정 기준을 바꾸면 선정 수와 정밀도·재현율이 달라지지만 순위 지표 자체가 바뀌지는 않습니다.

검증 고객을 모두 유지로 예측해도 정확도는 약 94.27%이므로 정확도만으로 모델을 고르지 않았습니다. 평균정밀도는 사다리꼴 방식의 곡선 면적과 정의가 같지 않으므로 보고서에서 명칭을 통일합니다.

## 4 튜닝과 과적합 점검

로지스틱 회귀는 규제 강도 0.1·1·10과 균형 가중치 사용 여부로 6개 설정을 비교했습니다. 학습 평균정밀도 0.1478과 검증 0.1701을 얻었고 수렴 경고는 없었습니다. 기본 검증 평균정밀도 약 0.1695 대비 차이가 작아 큰 개선으로 표현하지 않습니다.

서포트 벡터 머신은 규제 강도 0.01·0.1·1, 커널 계수 0.001·0.01, 가중치 사용 여부의 12개 설정을 비교했습니다. 기본 모델은 학습 평균정밀도 0.5152와 검증 0.1038의 차이가 컸습니다. 선택 모델은 학습 0.1384와 검증 0.1658로 과적합 징후가 완화됐지만 한 검증 표본만으로 일반화를 확정하지는 않습니다.

다층 신경망은 은닉층 32와 16 또는 64와 32, 규제 0.001 또는 0.01, 균형 가중치 사용 여부의 8개 설정과 기본 모델을 비교했습니다. 검증 평균정밀도를 학습 회차마다 확인하고 최고 회차의 가중치를 복원했습니다.

| 회차 | 학습 평균정밀도 | 검증 평균정밀도 | 해석 |
| --- | --- | --- | --- |
| 1 | 0.1433 | 0.1692 | 초기 상태 |
| 2 | 0.1520 | 0.1773 | 검증 최고 회차로 선택 |
| 17 | 0.1980 | 0.1353 | 학습 지표는 오르지만 검증은 하락해 조기 종료 |

15회 연속 개선이 없어 17회차에서 종료하고 2회차를 보존했습니다. 이후 회차의 학습 손실 감소만으로 좋은 모델을 고르지 않았습니다. 여러 후보와 회차를 같은 검증 자료에서 고른 선택 편향은 남습니다.

## 6 현재 앱 적용 조합

수정본은 정형 후보 13개와 시퀀스 후보 3개를 비중 10가지로 결합해 총 390개 조합을 최종 평가용 자료에서 비교했습니다. 저장된 선택은 에이다부스트 60%와 장단기 기억 신경망 40%입니다.

```
결합 출력 = 에이다부스트 출력 × 0.60 + 장단기 기억 신경망 출력 × 0.40
저장된 판정 기준 = 0.39822677201244505
화면 점수 = 결합 출력 × 100
화면 판정 기준 = 약 39.822677점
```

탐색 저장 수신자 곡선 면적은 0.899409입니다. 이 자료로 모델 조합과 비중뿐 아니라 판정 기준도 선택했으므로 새로운 고객에 대한 독립적인 최종 성능으로 제시하지 않습니다. 동일 자료에서 재실행만 한다고 독립성이 회복되지는 않습니다.

현재 조합과 저장 판정 기준을 검증 자료에 적용한 연결 점검은 다음과 같습니다.

| --- | --- |
| 평균정밀도 | 0.2968 |
| 수신자 곡선 면적 | 0.8989 |
| 정밀도 | 20.78% |

검증 자료 역시 학습 회차와 후보 설정을 점검하는 데 사용됐습니다. 이 값을 추가 미사용 평가의 대체물로 보지 않습니다. 개인 세 모델과는 입력과 선정 절차가 달라 결합만의 순수 개선 폭을 주장할 수 없습니다.

## 7 입력 재현과 앱 검증

제공된 분할 배열과 고객표로 예측했을 때 저장된 정형·신경망·조합 예측과 일치했습니다. 신경망 저장 예측과의 최대 차이는 확인한 환경에서 0이었습니다. 이는 추론 재현 확인이며 원시 로그의 기간·행동 번호 정합성까지 증명하지는 않습니다.

앱은 새로 학습하지 않고 저장된 모델을 불러옵니다. 운영 자료와 검증 기준을 분리하고, 새 고객·변경 집계·다른 날짜의 시퀀스가 없으면 예전 입력을 재사용하지 않습니다. 전처리 포함 모델과 판정 기준을 저장해 학습 때와 같은 입력 변환을 적용합니다.

다섯 화면 이동, 고정 확률 결합, 고객별 입력 검사, 저장·복원과 실제 대응 결과 입력 등 검사 20개가 통과했습니다. 이는 기능 검사이며 모델의 비즈니스 효과를 입증한 것은 아닙니다. 새 컴퓨터의 최초 설치는 별도 확인이 필요합니다.

## 8 비즈니스 활용과 효과 측정

운영자는 선정 목록과 고객별 불편 신호를 보고 대응을 결정합니다. 제안은 재방문 알림, 취향 재설정, 기술 지원, 요금제별 혜택 등 규칙 기반 예시입니다. 실제 발송과 고객별 효과 확인은 운영자가 수행합니다.

실제 효과를 보려면 같은 관리 대상 집단을 대응군과 비교군으로 무작위 배정하고 동일한 14일을 관찰합니다. 이탈률 차이, 추정 유지 고객 수, 연락·혜택 비용을 반영한 순이익을 함께 봅니다. 현재 실제 캠페인 결과는 수집하지 않았습니다.

## 9 현재 한계와 보완

가장 먼저 확인할 것은 시퀀스 생성 코드·사전과 시간 경계입니다. 정답과 연관된 미래 행동이 입력에 포함되지 않는지 생성 단계에서 검증해야 합니다. 현재 자료만으로 정보 누수가 없다고 확정하지 않습니다.

또한 범주 목록을 세 분할에서 합친 코드는 학습 기준으로 제한하고, 판정 기준 선택이 검증인지 최종 평가용 탐색인지 문서와 화면에서 통일해야 합니다. 원본을 활용한 추가 미사용 시점 평가를 만들 수 있는지 결정하고, 불가능하면 탐색 성능과 한계를 그대로 발표합니다.
