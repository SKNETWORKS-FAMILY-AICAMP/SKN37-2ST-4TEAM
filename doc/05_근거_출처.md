# 근거 수치와 출처

이 문서는 제공된 프로젝트 파일과 저장 보고서를 바탕으로 작성했습니다. 외부 연구의 성능을 가져오거나 새 모델을 학습하지 않았습니다.

## 전처리 근거

프로젝트의 원래 `reports` 폴더에 있는 다음 보고서를 확인했습니다.

| 자료 | 확인한 내용 |
|---|---|
| 원본 구조와 자료형 검사 | 전체 이벤트 수, 항목별 누락과 공백 |
| 누락 발생 상황과 비로그인 공통 번호 점검 | 곡 재생 이벤트 내 누락 없음, 공통 번호 제외 근거 |
| 숫자 범위와 가입 시각 검사 | 정상 범위와 가입 이전 이벤트의 고객·건수 |
| 분석 기간과 대상 정답 보고서 | 관찰·예측 시간 경계, 고객 수·정답 수 |
| 피처 정의서와 배포 저장 확인 | 피처 14개, 파일 구조와 공통 분할 |
| 행동 시퀀스 저장 확인 | 마지막 최대 50개 원시 행동, 짧은 시퀀스 1,859명, 인코딩 전 상태 |
| 수치 분포와 처리 기준 | 학습 자료 분포, 큰 값·0·음수의 보존 근거 |

전처리 수치 중 요금제·이용량 변화별 이탈 비율은 공통 통합표에서 학습 행만 선택해 다시 계산했습니다. 피처나 정답을 수정하지 않았습니다.

원래 데이터 안내는 제공자가 출처를 유다시티로 명시한다고 설명합니다. 생성 방식과 이용 조건은 아직 확인 항목입니다.

## 학습 근거

- 개인 로지스틱 회귀·서포트 벡터 머신·다층 신경망 폴더의 실험 요약과 기본 성능, 설정 비교, 선택 회차 이력
- 수정본 저장소 하위 폴더의 정형·신경망 학습 노트북과 최적 조합 탐색 노트북
- 수정본의 개별 후보 평가와 최적 조합 설정 파일
- 최종 앱의 모델 평가 보고 자료, 신경망 입력 확인과 통합 검사 결과

수정본은 지정한 저장소 폴더 안에 같은 이름으로 한 번 더 들어 있는 하위 폴더를 사용했습니다. 바깥의 이전 캐트부스트 65% 조합과 섞지 않았습니다.

## 수치 해석

- 개인 기준 모델 표는 검증 고객 2,721명과 이탈 156명입니다.
- 팀원 후보·조합 탐색 표는 최종 평가용으로 분리했던 고객 2,721명과 이탈 155명입니다.
- 현재 앱의 검증 연결 점검도 앞의 검증 집단이지만 시퀀스 입력과 조합 선택 절차가 달라 단순 개선 폭으로 비교하지 않습니다.
- 평균정밀도 계산값과 사다리꼴 정밀도 재현율 곡선 면적을 같은 정의로 단정하지 않습니다.
- 조합의 약 0.8994는 최종 평가용 자료로 선택한 참고값입니다. 독립적인 최종 성능이 아닙니다.

## 재현용 요약

[문서 수치 근거](evidence/문서_수치근거.json)에 탐색 집계, 개인 실험 요약, 팀원 저장 수치와 자료 지문을 보관했습니다.
문서 안 표는 표시 자릿수에 따라 반올림했습니다. 작은 차이는 반올림 때문일 수 있으므로 원래 값은 근거 파일을 확인하세요.

신규 캠페인 성과나 새 최종 성능은 이 파일에 만들어 넣지 않았습니다. 화면 확인 이미지는 현재 최종 조합 연결 상태의 실제 캡처입니다.
