# 인공지능 데이터 전처리 결과서

작성 기준은 2026년 10월 30일입니다. 대상은 음악 스트리밍 가입 고객 이탈 예측 팀 프로젝트이며 현재 증빙으로 확인되는 처리와 미확인 사항을 구분합니다.

## 1 비즈니스 목표와 데이터 범위

최근 28일의 이용 기록을 통해 다음 14일 안에 해지할 위험이 있는 고객을 선별합니다. 운영자는 해당 고객의 불편 신호를 확인하고 연락·추천·혜택을 제안합니다. 실제 대응의 효과는 별도 관찰이 필요합니다.

원본은 줄마다 하나의 객체가 있는 이벤트 로그이며 26,259,199건입니다. 원본 파일은 약 11.88기비바이트입니다. 제공 안내상 출처는 유다시티입니다. 생성 방식·모의 데이터 여부·이용 조건은 추가 확인해야 하므로 특정 실제 음악 서비스의 운영 자료라고 단정하지 않습니다.

원본 시간 범위는 2018년 10월 1일부터 12월 1일까지입니다. 고객 집계의 시간은 협정 세계시 기준이며 시작을 포함하고 끝을 제외합니다.

## 2 원본 구조와 누락 검사

전체 기록의 구조·자료형·누락·공백·숫자 범위·범주 값을 검사했습니다. 확인용 앞 5건 검사에 그치지 않고 전체 원본을 순차적으로 읽어 검사했습니다.

| 확인 사항 | 결과 | 처리 근거 |
| --- | --- | --- |
| 곡·가수·길이 누락 | 각각 5,408,927건 | 비재생 이벤트에서 발생하는 구조적 누락이며 곡 재생 이벤트 내 누락은 없음 |
| 일부 가입자 속성 누락 | 각각 778,479건 | 하나의 공통 번호에 모인 비로그인·방문자 기록과 일치 |
| 가수·곡 제목 앞뒤 공백 | 가수 1,361건, 곡 제목 15,405건 | 이 두 문자열은 현재 14개 피처에 사용하지 않음. 원본 전체 공백을 수정했다고 주장하지 않음 |
| 필수 항목 | 고객 번호·이벤트 종류·시각·세션 번호 | 최종 집계와 입력 검사에서 자료형·누락·범위를 확인 |
| 숫자 기본 범위 | 음수 세션·음수 세션 순번·0 이하 곡 길이 없음 | 정상 범위의 큰 값만으로 오류나 자동화 이용자로 단정하지 않음 |

비재생 기록에 곡 정보가 없다는 이유로 행을 일괄 삭제하면 오류·도움말·광고 등 유용한 신호를 잃게 됩니다. 누락의 발생 상황에 따라 처리했습니다.

## 3 비로그인 공통 번호와 가입 시각 처리

공통 번호 `1261737`은 비로그인 774,285건과 방문자 4,194건으로 총 778,479건입니다. 모든 기록에 가입 시각이 없어 가입 고객 한 사람의 행동으로 집계할 근거가 부족했습니다. 이후 고객 피처와 정답 생성에서 제외하고 원본은 보존했습니다.

제외 후 원본 범위 검사는 25,480,720건을 대상으로 했습니다. 고객 22,277명 중 144명에게 가입 시각보다 앞선 이벤트 11,484건이 있었고, 그중 19명은 모든 이벤트가 가입 이전이었습니다. 어떤 시각이 잘못됐는지 확정할 수 없어 가입 기간과 가입 후 활동량 같은 피처를 제외했습니다. 가입 시각을 임의로 바꾸거나 이 문제만으로 고객의 행동·해지 기록을 삭제하지 않았습니다.

| 항목 | 정의 |

## 7 분할과 모델별 변환

| 구분 | 고객 수 | 이탈 고객 수 | 이탈 비율 |
| --- | --- | --- | --- |
| 학습 | 12,697 | 724 | 5.70% |
| 검증 | 2,721 | 156 | 5.73% |
| 최종 평가용으로 분리한 자료 | 2,721 | 155 | 5.70% |

공통 분할은 고객 단위의 약 70 대 15 대 15 비율이며 이탈 비율을 비슷하게 유지했습니다. 고객의 중복·누락과 통합·개별 파일 간 일치를 확인했습니다. 이 방식은 같은 기준일의 다른 고객을 평가하며, 다른 달의 성능을 검증한 것은 아닙니다.

개인 기준 모델 실험은 수치형 표준화 기준을 학습 자료에서만 계산하고 무료·유료를 이진 인코딩했습니다. 검증·앱 입력에도 저장된 동일 변환을 적용합니다. 트리 계열은 정형 수치의 표준화 없이 사용하며 요금제는 무료 0, 유료 1로 고정합니다.

팀원 수정본의 범주 목록 생성 코드는 학습·검증·최종 평가 자료를 합칩니다. 정답을 사용한 변환은 아니고 현재 범주는 무료·유료 두 가지이지만, 엄격한 분할 원칙에 맞춰 월요일에는 학습 자료 또는 사전에 고정한 대응표만 사용하도록 정리해야 합니다.

현재 고객별 원본 피처표는 스케일링 전 자료입니다. 고객 번호·정답·분할 열은 학습 입력에서 제외해야 합니다. 최종 고객표는 16열, 분할 열이 포함된 통합표는 17열입니다.

## 8 행동 시퀀스와 현재 연결 범위

원시 시퀀스 파일은 정형 자료와 고객·분할·정답이 일치하는 18,139명이며, 고객별 마지막 최대 50개 행동을 보관합니다. 시각이 같으면 원본 줄 번호로 순서를 정합니다. 행동이 50개 미만인 고객은 1,859명이며 이 파일 자체에는 패딩과 숫자 인코딩을 적용하지 않았습니다.

수정된 신경망 학습 코드는 별도로 제공된 학습·검증·최종 평가 배열을 해당 분할 고객표의 같은 행과 연결합니다. 배열은 고객당 길이 50이며 확인된 번호 범위는 0부터 14입니다. 신경망의 입력 범위는 0 이상 50 미만입니다.

현재 앱은 이 준비된 배열을 고객 번호와 기준일에 연결합니다. 저장 예측과 재현값의 일치를 확인했지만, 이것이 원시 행동과 숫자 배열의 의미·관찰 기간 정합성을 증명하지는 않습니다. 행동 사전·자르기·패딩·미등록 행동 규칙과 생성 코드가 필요합니다.

신규 고객·다른 기준일·변경 집계에는 대응하는 시퀀스가 없으면 자동으로 예전 입력을 붙이지 않습니다. 번호가 명시된 새 입력을 별도로 등록해야 하며 원시 로그의 자동 변환은 아직 완성하지 않았습니다.

## 9 재검사와 남은 작업

고객 번호 공백·중복, 잘못된 자료형, 결측·무한대, 음수 횟수, 활동 일수 범위, 이용 등급, 최근 재생 계산식을 검사합니다. 저장 전후 고객·피처·정답과 분할 일치도 확인했습니다. 운영 자료 변경과 기본값 복원에는 이전 자료 보관을 사용합니다.

월요일에는 원본 출처와 이용 조건, 시퀀스 생성 규칙, 범주 변환의 학습 자료 한정 원칙을 가장 먼저 확인합니다. 실제 이탈 감소 결과는 아직 없으며 전처리 완료와 비즈니스 효과 입증은 구분합니다.
